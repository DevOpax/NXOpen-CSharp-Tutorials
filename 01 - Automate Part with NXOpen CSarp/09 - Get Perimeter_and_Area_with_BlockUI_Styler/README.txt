I used Visual Studio Enterprise 2022 and the Siemens NX2506 version.

# Installation

1 - Place Test.dlx somewhere on your computer
2 - Create a new project in Visual Studio
3 - Import the Test.cs in your project
4 - Change the path to the DLX file (line 143)
5 - Build the solution
6 - Run in NX
