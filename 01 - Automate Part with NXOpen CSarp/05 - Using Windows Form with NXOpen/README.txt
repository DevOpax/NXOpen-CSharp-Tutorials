# Using Windows Form with NXOpen C#

Hi,
The ZIP file contains the source code of my tutorial '#5 Using Windows Form with NXOpen C#' on my YouTube channel.
Video : https://youtu.be/TJW6Q_5f3ms?si=6l7lmrm0Dr5Gq8e2

I used Visual Studio Enterprise 2022 and the Siemens NX2506 version.

# Installation

1 - Unpack the ZIP file
2 - Place the L_Profile_Base.prt file somewhere on your computer
3 - Modify the path of the 'template' variable in form1.cs file.
4 - Modify the 'workdir' variable. This is the path where the new parts will be saved.
5 - Add references to the NXOpen Library
6 - Compile and run the exe in Siemens NX
